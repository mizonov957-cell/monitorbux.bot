# MonitorBux Bot 📊

Telegram-бот для мониторинга буксов. Автоматически собирает данные с workprom.ru и предоставляет удобный интерфейс для просмотра.

## Возможности

- 📊 **Мониторинг** — просмотр всех активных буксов
- 🔍 **Поиск** — быстрый поиск по названию
- 📈 **Статистика** — общая статистика по буксам и пользователям
- 🔄 **Обновление** — парсинг актуальных данных
- 🤖 **Bothost** — партнёрская ссылка на хостинг
- 🔗 **Linkslot** — партнёрская ссылка на рекламу
- 💼 **Добавить букс** — предложение добавить новый букс

## Админ-панель

Доступна по команде `/admin` для пользователя с ADMIN_ID:

- ➕ Добавить букс
- 🗑 Удалить букс
- ✏️ Редактировать букс
- 🌐 Парсинг данных
- 📊 Статистика
- 📢 Рассылка
- 👥 Пользователи
- 📋 Логи парсинга
- 🔗 Партнёрки
- ⏱ Интервал

## Установка

1. Клонируйте репозиторий
2. Скопируйте `.env.example` в `.env` и заполните данные
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите: `python bot.py`

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `ADMIN_ID` | ID администратора |
| `DB_PATH` | Путь к базе данных (по умолчанию bux.db) |
